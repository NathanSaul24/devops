# devops
X's and O's development application.

To Run:

1. Open devops directory and open terminal
2. Type the following commands:
3.   make all
4.   cd webapp
5.   python3 app.py

6. Go to http://localhost:5000

7. For testing, run the game in command line ( ".\game.exe" after compile), play a game, then do: make test
